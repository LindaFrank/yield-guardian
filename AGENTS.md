# Project Architecture

- The public `/` route is the temporary Coming Soon page; authenticated testers use `/auth` and enter the application at `/app` so launch messaging remains isolated from the working product.
- Stock prices come from two FMP keys selected per request — the personal key only for the owner's own sign-in arriving from the Lovable preview, the commercial key for everyone else and the public site — because the personal plan is personal-use only and must never serve other people; cached quotes and dividends are therefore stored per key (`stock_cache.source`) so data fetched under one plan can't display under the other.
- Commercial closing prices use one shared CSV snapshot per completed New York trading date, with a service-only atomic four-hour retry lease and per-ticker EOD fallback; this avoids repeated restricted bulk downloads and keeps unfinished session prices out of portfolios. Company details reuse commercial cached quotes, never the profile's live price. Personal requests never use the bulk snapshot.
- Stock-data request validation lives in its function-local request module so regression tests exercise the deployed schema; keep-alive pings allow omitted or empty tickers while data actions require a nonempty array.
