# Replace the Yield Stepper

## Change
- Remove the current −/+ buttons beside the 10% label.
- Add a compact numeric percentage field in the same location.
- Let users type a value directly or use the field’s up/down controls.
- Keep the allowed range at 1%–10% and increments at 0.5%.
- Keep the existing draggable and clickable yield bar synchronized with the field.
